# Tasks: add-pass-bridge

Citations are as read while designing this change, on 2026-09-16; re-read the named lines before editing, since line numbers drift.
This change depends on `extend-bridge-fields` being applied first: `modules/flake/safix/fields.nix`, `modules/flake/safix/reserved.nix` (all six reserved words, `pass` among them), `crates/safix-core/src/endpoint.rs` (`Endpoint`, `Record`, `Existing`, `Capabilities`), `model::{Fields, FieldValue}`, `ResolvedFields`, the single `judge` over `Record`s, `Outcome::FieldsDiverged`, and `Error::{FieldUnsupported, FieldSourceInArgv}`.
Nothing here edits either of those two nix files or `endpoint.rs`; if a task appears to need an edit there, stop and raise it, because a second definition beside them is the thing this ordering exists to prevent.
No real secret name, user name, recipient or store path enters this repository; fixtures use `alice`, `bob` and `carol`, synthetic `age1` strings, and stores under the fixture's own scratch directory.
Where a task says "hold", add a check that fails when the claim stops being true, not a sentence asserting it.
The decisions this change rests on are `design.md`'s D1 through D11; each group names the ones it realizes.
