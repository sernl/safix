Citations are as read while designing this change, on 2026-09-16; re-read the named lines before editing, since line numbers drift.

It consumes, and never edits: `modules/flake/safix/reserved.nix` (already carrying `"bitwarden"`), `modules/flake/safix/fields.nix`, `crates/safix-core/src/endpoint.rs` (`Record`, `trait Endpoint`, `Existing`, `Capabilities`), the single `judge`, `model::{Fields, FieldValue}`, `ResolvedFields`, `Error::{FieldUnsupported, FieldSourceInArgv}`, and `Outcome::FieldsDiverged`.

Where a task says "hold", add a check that fails when the claim stops being true, not a sentence asserting it.
